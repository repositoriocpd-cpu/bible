## 🎯 Resumo de Uso Rápido

### Quando usar cada cor

| Cor | Uso |
|-----|-----|
| **#E89946** | CTAs principais, ícones importantes, acentos em títulos |
| **#4ADE80** | Indicadores de sucesso, fidelidade ALTA, confirmações |
| **#FBBF24** | Avisos, fidelidade MÉDIA, alertas leves |
| **#F87171** | Erros, fidelidade BAIXA, alertas críticos |
| **#1A1A1A** | Cards, navbar, painéis elevados |
| **#0F0F0F** | Background principal, foreground em botões |
| **#F5F5F5** | Texto principal, títulos |
| **#9CA3AF** | Texto secundário, placeholders, metadados |
